1. 安装 miniconda
2. 使用 miniconda 安装一个 Python 3.11 环境
3. 在环境 pip 中安装 requirements.txt
4. 安装 Playwright 的 Chromium 运行时：python -m playwright install chromium （Linux 还需 python -m playwright install-deps chromium）
5. 将 memes.zip.001 与 memes.zip.002 拼接后解压到环境 site-packages/meme_generator/ （解压结果为 site-packages/meme_generator/memes/）
6. 将 data/nonebot_plugin_meme_stickers/_shared/YurukaFangTang.ttf 安装到系统
7. 生成 .env.prod 配置：推荐跑交互式向导 python 一键部署脚本/_setup_env.py ，它会一问一答带你填完（输入 ? 看说明，q 退出，已有配置会先备份）；也可以手动复制一份 .env.prod_example 至 .env.prod 后自己改
8. 在 utils/ssl/ 下准备 privkey.key 与 fullchain.pem 。bot.py 硬依赖这两个文件，缺失无法启动；本地测试可用 openssl 生成自签名证书
9. 整理启动脚本：把当前系统对应的那个重命名为统一名字，并删掉其余的
   - Linux：launch_linux.sh 改名为 launch.sh ，删除 launch_macos.command 与 launch_windows.bat
   - macOS：launch_macos.command 改名为 launch.command ，删除 launch_linux.sh 与 launch_windows.bat
   - Windows：launch_windows.bat 改名为 launch.bat ，删除 launch_linux.sh 与 launch_macos.command
10. 主目录启动：Linux 用 ./launch.sh ，macOS 用 ./launch.command （也可在 Finder 里双击），Windows 用 launch.bat

也可直接使用 一键部署脚本/ 下对应系统的部署脚本自动完成 1-9 步，详见 一键部署脚本/README_CN.md 。
