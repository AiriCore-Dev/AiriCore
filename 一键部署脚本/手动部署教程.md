1. 安装 miniconda
2. 使用 miniconda 安装一个 Python 3.11 环境
3. 在环境 pip 中安装 requirements.txt
4. 安装 Playwright 的 Chromium 运行时：python -m playwright install chromium （Linux 还需 python -m playwright install-deps chromium）
5. 将 memes.zip.001 与 memes.zip.002 拼接后解压到环境 site-packages/meme_generator/ （解压结果为 site-packages/meme_generator/memes/）
6. 将 data/nonebot_plugin_meme_stickers/_shared/YurukaFangTang.ttf 安装到系统
7. 复制一份 .env.prod_example 至 .env.prod ，修改 .env.prod 中的配置项
8. 在 ssl/ 下准备 privkey.key 与 fullchain.pem 。bot.py 硬依赖这两个文件，缺失无法启动；本地测试可用 openssl 生成自签名证书
9. 整理启动脚本：把当前系统对应的那个重命名为统一名字，并删掉其余的
   - Linux：launch_linux.sh 改名为 launch.sh ，删除 launch_macos.sh 与 launch_windows.bat
   - macOS：launch_macos.sh 改名为 launch.sh ，删除 launch_linux.sh 与 launch_windows.bat
   - Windows：launch_windows.bat 改名为 launch.bat ，删除 launch_linux.sh 与 launch_macos.sh
10. 主目录启动：Linux / macOS 用 ./launch.sh ，Windows 用 launch.bat

也可直接使用 一键部署脚本/ 下对应系统的部署脚本自动完成 1-9 步，详见 一键部署脚本/README_CN.md 。
