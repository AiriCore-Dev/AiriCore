# Airi Point Salad 详细帮助与网页玩法文档设计

## 目标

将 `,sl rl` 的详细帮助收敛为六个清晰的合并转发节点，并提供一套可直接复制到网站文章目录的 MDX 玩法文档与静态配图。网页配图只复用 `plugins/airi_point_salad/assets/` 中的现有素材，由本地绘图程序添加箭头、线条、圈注和中文标签，不调用图像生成服务。

## 合并转发结构

### 第一板块：大标题

完全保留当前工作区中的标题与正文，不修改文字、标点或换行：

- 标题：`Airi-Point-Salad`
- 正文：`MORE MORE JUMP！得分沙拉\n摸摸酱们也要玩美式桌游！`

### 第二板块：游戏简介

使用用户指定的最终文案：

> 一款适合 2–6 人在群聊中游玩的选牌桌游。玩家轮流从市场取得角色牌或计分牌，通过角色组合、翻牌规划和不同计分条件积累分数，最后总分最高者获胜。

### 第三板块：指令列表

以速查表形式完整列出：

- 根命令：`,沙拉`、`,salad`、`,sl`
- 创建房间：速度与模式参数的中文、英文全称和缩写
- 房间操作：加入、退出、开始、结束
- 回合操作：拿计分牌、拿两张角色牌、翻牌
- 六名 Center 的技能指令格式与必要参数
- 查看桌面、查看详细帮助
- 命令必须使用英文逗号开头，英文参数不区分大小写

指令板块只解释如何输入，不重复网页文档中的完整规则推导。

### 第四板块：桌游玩法文档

说明网页文档包含图解规则、完整流程、计分方式、Center 技能与 Live Mission，并附可点击的占位网址：

`https://example.com/airi-point-salad`

占位网址集中定义，便于部署后手动替换。

### 第五板块：注意事项

集中说明影响实际开局的约束：

- 仅支持 2–6 人群聊游戏
- 只有房主可以开始，房主或群管理员可以结束
- 快速局与标准局对应的牌量
- 每回合翻牌次数、拿牌数量和行动顺序限制
- Center 技能仅混合模式可用，每局最多成功使用一次
- Live Mission 仅混合模式启用，每回合最多领取一项
- 大厅 15 分钟、对局 30 分钟无合法操作自动关闭
- 查看桌面或帮助不刷新超时计时

### 第六板块：版权信息

完全保留当前工作区中的版权内容，不修改文字、标点或换行。

## MDX 部署包

部署包位于 `plugins/airi_point_salad/web_help/`：

- `index.mdx`：使用参考文章一致的 YAML frontmatter 字段，包括标题、发布日期、简介、标签、分类、草稿状态和封面图
- `cover.png`：网页封面
- `market-guide.png`：三列市场、计分牌位置与 `A1–C2` 角色牌位置
- `turn-flow.png`：可选翻牌到必须拿牌再到补牌换人的流程
- `scoring-guide.png`：五类计分牌与角色牌组合关系
- `center-skills.png`：六名 Center、技能用途和关键指令
- `mixed-mode.png`：Center 与 Live Mission 在混合模式中的作用

MDX 使用相对图片路径，复制整个目录后即可部署。正文覆盖游戏目标、准备、模式差异、完整回合、拿牌、翻牌、计分、六名 Center、Live Mission、结束与并列排名、完整命令示例和常见错误。

## 配图设计

所有配图基于现有标题、卡面底图、六张角色立绘和六张 Q 版角色图。图片由 Pillow 离线合成，使用统一的深蓝、粉色与金色视觉体系，并添加：

- 高对比箭头表示行动顺序和拿牌方向
- 圆圈与描边框标记市场坐标和可选区域
- 半透明注释框解释规则与限制
- 中文短标签辅助阅读，避免把长段正文烘焙进图片

最终图片使用 PNG，不引用本地绝对路径，不依赖生成时的临时文件。

## 代码边界

- `help.py` 只负责六板块的稳定文案数据
- `__init__.py` 继续负责构造和发送合并转发消息
- 网页文档与图片放在独立的 `web_help/` 目录，不参与 Bot 运行时加载
- 不改变游戏规则、状态机、存档或渲染缓存
- 保留工作区中与本任务无关的现有修改

## 错误处理

合并转发发送失败时继续返回现有中文失败提示。网页地址为静态文本，不在 Bot 运行时请求网页，因此网页不可用不会影响插件指令处理。

## 验证标准

- `help_sections()` 恰好返回六个节点，顺序符合需求
- 第一与第六板块和当前工作区内容逐字一致
- 第二板块与用户指定文案逐字一致
- 第三板块覆盖全部命令及六名 Center 技能格式
- 第四板块包含唯一、明确的网址占位符
- 第五板块覆盖时间、人数、权限与行动限制
- MDX frontmatter 可解析，所有相对图片引用均存在
- 所有 PNG 可解码、尺寸一致且无裁切、重叠或不可读文字
- 通过 Ruff、Python AST/编译检查与项目插件加载验证
