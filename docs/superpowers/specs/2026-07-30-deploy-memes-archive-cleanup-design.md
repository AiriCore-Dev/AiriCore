# 一键部署完成后清理 memes 分卷

## 目标

Linux、macOS、Windows 一键部署脚本只有在全部部署步骤成功执行后，才删除项目根目录中的 `memes.zip.001` 与 `memes.zip.002`。

## 实现

- 在三份部署脚本整理完启动脚本后、输出“部署完成”前执行清理。
- Linux 与 macOS 分别检查两个文件是否存在，存在则删除并输出中文提示。
- Windows 使用 `Test-Path` 检查并通过 `Remove-Item -Force` 删除，输出相同语义的中文提示。
- 文件已不存在时直接跳过，保证重复执行不会因清理步骤失败。
- 删除失败时沿用部署脚本现有的错误终止机制，不输出“部署完成”。

## 不变范围

- `_setup_memes.py` 继续只负责校验、拼接和解压，不提前删除分卷。
- memes 的解压路径、临时合并文件清理和其他部署步骤保持不变。

## 验证

- 先用临时静态验证脚本证明当前三平台脚本缺少成功后清理逻辑。
- 修改后验证三平台脚本都在“部署完成”提示前删除两个项目根目录分卷。
- 对 Linux 与 macOS 脚本执行语法检查。
- 确认 Windows 脚本仍保留 UTF-8 BOM。
- 验证结束后删除本次创建的临时测试脚本及结果文件。
