# airi_point_salad 生成式美术重制设计

## 目标

重制 `airi_point_salad` 的视觉资产。用户提供的六张角色图和 MORE MORE JUMP！Logo 仅作为人物设定、服装特征与主题色参考，不再直接裁切、贴入或发送。最终牌面采用分层合成：生成牌底、生成角色立绘、生成姓名铭牌、程序写入准确文字、程序补精确外框。

重制不改变游戏规则、指令、存档格式、并发模型或 NoneBot 接入。

## 视觉语言

整套素材使用统一的精致日系新艺术塔罗风格：象牙白底、深海军蓝、古典金、角色主题色、细腻宝石、薄纱、植物曲线、圆形光环与舞台星芒。画面保持 MORE MORE JUMP！的明亮偶像感，同时具备塔罗牌的仪式感和收藏感。

禁止直接复刻原图姿势或服装，禁止现代便服、夸张搞怪动作、过度暴露、厚重暗黑哥特、写实摄影、3D 渲染、低幼贴纸感、生成文字、水印和签名。

## 角色立绘

六张立绘分别生成，统一使用同一份画风母版、固定提示词结构、线条密度、脸部精细度、材质语言、光源方向和色彩关系。每张为竖向半身或四分之三身构图，不包含文字、Logo、姓名铭牌或卡片边框。人物与背景之间保持清晰轮廓，便于去底后叠加。

六名角色重新设计为同一系列的“新艺术塔罗偶像礼装”。共享象牙白、深海军蓝、金色镶边、半透明薄纱和宝石饰件，但剪裁、剪影、姿势和象征元素各自不同：

- 花里实乃理：嫩绿、四叶草与麦穗，轻盈短披肩，向前伸手的迎宾姿态。
- 桐谷遥：深蓝、羽翼与水波，流线型长摆，沉静侧身姿态。
- 桃井爱莉：粉红、鸢尾与心形宝石，花瓣层叠礼服，自信优雅的转身姿态。
- 日野森雫：银蓝、百合与露珠，长纱与垂坠裙摆，舒展回眸姿态。
- 初音未来：青绿、星芒与音律丝带，不对称轻纱礼装，悬浮般的引导姿态。
- 镜音铃：金黄、太阳与麦穗，短斗篷与放射状裙摆，轻快但克制的跃动姿态。

角色身份依靠参考图中的发型、发色、眼睛、面部特征和核心配色保持可识别；服装、姿势、手势和局部装饰全部重新创作。六张应形成不同的动作方向、轮廓与视觉重心，同时保持优雅。

## Q 版角色徽章

为六名角色分别生成统一风格的迷你 Q 版小人。Q 版可以是头像、胸像或半身动作，不要求全身站姿。所有图标使用一致的头身比例、描线粗细、阴影方式、表情精细度、镜头距离和背景处理，服装沿用对应的新艺术塔罗偶像礼装。

Q 版素材生成在干净、低干扰的单色背景上，运行时由程序裁为圆形金边徽章。角色可有不同表情和手势，但不得出现某些角色为头像、某些角色为极远全身的尺度漂移。

## 生成牌底与标题

生成以下共享视觉组件：

- `title.png`：包含准确文字 `MORE MORE JUMP！` 和 `POINT SALAD` 的完整标题图，使用清新偶像色、古典金和新艺术装饰。生成后逐字符检查；任何错字、漏字或重复字均不得采用。
- `front_base.png`：5:7 竖向无文字正面牌底母版，包含新艺术内饰、柔和中心光场和贴近牌边的装饰曲线，不包含人物、姓名铭牌或生成文字。程序使用角色主题色进行低强度着色，结构始终完全相同。
- `back_base.png`：5:7 竖向无文字背面牌底，使用象牙白、浅青、浅粉与金色，为标题、Q 版徽章、规则和分数保留明确区域。
- `nameplate.png`：无文字姓名铭牌母版，使用深海军蓝、象牙白和金色细边。六张角色牌复用同一结构，由程序写入准确中文名和英文标识。

程序保留最外层精确双金边，生成牌底负责内部纹样、材质和光影。这样既保留生成美术的丰富度，也保证所有牌边、圆角、文字和安全区严格一致。

## 统一性生成流程

使用内置图像生成能力，不使用 CLI 回退。先生成一份临时视觉母版，确定线条、材质、光影、金色用法与新艺术纹样；之后每一种素材使用固定提示词模板和同一母版参考。

角色立绘每次同时提供对应人物参考和共享视觉母版。Q 版每次同时提供对应人物参考、对应新立绘和共享 Q 版母版。牌底、背面、姓名铭牌与标题共享同一套色彩和装饰术语。

立绘优先在纯色背景上生成，再使用本地图像处理去除背景。若头发、薄纱或透明材质导致内置纯色去底无法达到干净边缘，则暂停并征求用户是否允许使用需要 API 密钥的原生透明 CLI 回退，不擅自切换模型或路径。

每张生成结果均检查人物身份、服装设计、姿势差异、手指结构、文字准确性、边缘完整性、画风一致性和叠加安全区。不合格结果只针对单一问题重新生成。

## 渲染改造

`renderer.py` 改为从 `assets/generated/` 读取素材：

```text
角色正面 = 着色后的 front_base
          + 对应透明 portraits 图层
          + nameplate 图层
          + 程序姓名文字
          + 程序双金边

计分背面 = back_base
          + title
          + chibi 圆形徽章
          + 程序规则与分数
          + 程序双金边
```

桌面标题改用生成的 `title.png`。计分牌和桌面上的六种元素全部改为生成 Q 版徽章，不再从角色原图裁头像。角色主题色仍由程序控制，保证文字对比度和牌面识别速度。

## 验证标准

- 运行时代码和最终渲染不读取或贴入任何 `assets/references/` 文件。
- 六张角色立绘服装、姿势和剪影各异，身份清晰且整体优雅。
- 六张立绘与六个 Q 版徽章在描线、脸部、光影、材质和构图尺度上分别统一。
- 标题逐字符准确显示 `MORE MORE JUMP！POINT SALAD`。
- 正面、背面和姓名铭牌均来自生成图像，而不是纯 Pillow 几何替代。
- 卡片尺寸保持 750 × 1050，最外层双金边、姓名和规则文字位置一致。
- 计分牌在桌面缩略尺寸下仍能区分六个 Q 版角色。
- 所有发送图片继续使用 `base64://`，常规及最坏桌面低于 3 MB。
- 原有游戏、指令、持久化和插件加载测试无回归。
- 临时母版、失败变体、测试脚本和预览在验收后删除。
