# airillmquery LLM 调用统计设计

## 目标

新增仅限 superuser 使用的 `airillmquery` 命令，按北京时间统计各业务来源调用不同 LLM 模型的成功次数，并支持按今天、最近 N 天、指定日期、月份或年份查询。统计数据跨重启持久化且不自动清理。

## 方案选择

采用共享统计器，由各 LLM 调用链在模型 API 成功返回后上报来源和实际模型。

未采用全局拦截 OpenAI 客户端，因为拦截层无法可靠识别业务来源。未采用各插件独立持久化，因为这会重复日期解析、并发保护、原子写入和查询汇总逻辑。

## 统计来源

固定显示以下六类来源：

- 对话
- 对话机制
- 海龟汤
- 水表
- 心愿瓶审核
- RCON翻译

`airi_llm` 的普通回复归入“对话”，结构化分析、记忆、情绪、话题、知识等后台调用归入“对话机制”。其余来源分别对应 `airi_turtle_soup`、`airi_kokomi_wows`、`airi_wish_bottle` 和 `airi_mcrcon`。

## 成功口径

一次 `chat.completions.create` 调用未抛异常并返回响应即视为成功，立即按本次请求使用的实际模型计数。

后续出现空内容、响应字段异常、JSON 解析失败、NL2C 解析失败或业务校验失败，不撤销该次计数。若业务逻辑随后尝试备用模型，备用模型成功返回时另计一次。抛出异常的模型尝试不计数。

## 数据结构与持久化

新增共享统计模块，内存结构为：

```text
日期 -> 来源 -> 模型 -> 成功次数
```

日期使用 UTC+8 自然日，格式为 `YYYY-MM-DD`。所有日期桶集中保存在 `data/airi_llm/usage_stats.pk`，以避免产生大量小文件。统计器使用线程锁保护并发更新，数据变更后标记为 dirty，每 15 秒通过临时文件替换的方式原子落盘；NoneBot 正常关闭时强制保存。读取失败时先把原文件改名保留为 `.corrupt`，再记录中文警告并以空统计启动。

历史数据不设置保留期限。查询接口只返回不可变快照，避免命令汇总期间与写入互相影响。

## 调用链接入

共享降级调用器增加可选来源参数。海龟汤、水表、心愿瓶审核和 RCON 翻译传入各自来源；未传来源的其它调用不产生统计。计数发生在 OpenAI 请求成功返回后、文本提取和校验之前。

`airi_llm` 使用自己的调用循环：普通回复路径上报“对话”，结构化请求路径上报“对话机制”。记录的模型始终是当前循环实际请求的模型，包括备用模型。

## 命令与参数

`airillmquery` 使用可接收参数的命令 matcher，配置 `SUPERUSER` 权限、优先级 5 并阻断后续匹配。

参数规则：

- 无参数：今天。
- 纯数字：最近 N 个自然日，包含今天；`1` 等价于今天。
- 四位纯数字：优先解释为年份。
- `YYYY-MM-DD`：指定日期。
- `YYYY-MM`：指定月份。
- `YYYY`：指定年份。

日期必须通过真实日历校验，N 必须大于 0。参数两侧空白忽略，额外参数、无效日期、零或负数均返回中文用法提示。

## 查询结果

查询将所选日期范围内的日期桶聚合后输出：

- 查询范围。
- 成功调用总数。
- 各来源成功总数。
- 每个来源下各实际模型的成功次数。

来源按固定列表顺序展示，模型按次数降序、名称升序展示。没有数据的来源不展示；整个范围无数据时返回明确的中文无数据提示。月份、年份和最近 N 天查询只展示范围聚合，不逐日展开，避免长消息。

## 错误处理

统计失败不得影响业务 LLM 调用结果。内存计数或持久化异常只记录中文警告。命令读取统计失败时返回中文错误提示，不泄露文件路径、配置或异常堆栈。

## 验证

验证覆盖：

- API 抛异常不计数，成功返回立即计数。
- 空内容和解析失败仍计数。
- 主模型及备用模型多次成功分别计数。
- 六类来源映射正确。
- UTC+8 跨日分桶正确。
- 并发更新不丢计数，持久化后可回载。
- 无参数、最近 N 天、日、月、年及四位数字年份优先级正确。
- 非法参数与无数据提示正确。
- matcher 仅允许 superuser 使用。
- 相关插件加载、编译及现有测试无回归。
