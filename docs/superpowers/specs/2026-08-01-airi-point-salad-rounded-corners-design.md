# Airi Point Salad 卡牌圆角设计

## 目标

为角色牌正面和所有计分牌背面的四个角增加轻微圆弧。原始卡牌尺寸保持 `750×1050`，圆角半径固定为 `24px`，不改变现有边框、立绘、文字、头像和编号布局。

## 实现

渲染层增加统一的卡牌圆角处理函数。卡面内容全部绘制完成后，生成四倍分辨率的灰度圆角蒙版，再缩小到卡牌尺寸，以获得平滑的抗锯齿边缘；蒙版与卡面原有 Alpha 相乘，四角变为透明，四边中部保持完全不透明。

角色牌正面和计分牌背面都在进入渲染缓存前应用同一蒙版，缓存保存圆角处理后的最终 RGBA 卡面。缓存命中时直接复制最终卡面，不重复生成蒙版或裁切。风险牌的专用绘制分支也必须经过圆角处理。角色头像图标不属于卡牌，不改变其现有圆形蒙版。

桌面渲染继续缩放并合成已经完成的 RGBA 卡面，因此市场中的计分牌和角色牌会自然保留同比例圆角，桌面背景从四角透出，不需要第二套裁切逻辑。

## 缓存与兼容

圆角只改变渲染结果，不改变卡牌数据、缓存键、存档或命令。`ram` 与 `balanced` 模式缓存圆角后的最终卡面，`disk` 模式继续按现有规则即时生成且不保留 Python 图片缓存。进程重启后缓存会按现有机制重新生成；base64 图片输出保持不变。

## 验证

- 角色牌正面和普通计分牌背面的四个角 Alpha 为 0。
- 风险牌背面的四个角同样透明。
- 四边中点与卡面中心保持完全不透明。
- 卡面尺寸仍为 `750×1050`，模式仍为 RGBA。
- 圆角边缘存在半透明抗锯齿像素。
- 缓存命中返回的卡面仍保留相同圆角 Alpha，不重复处理卡面。
- 真实渲染角色牌、普通计分牌、风险牌和桌面，人工确认圆弧轻微、边框未被明显截断、桌面背景能从圆角透出。
- 现有卡面文字、风险牌双色效果、比较牌单行条件和桌面布局不受影响。
