# AiriCore 魔裁DIY制作帮助

## 安安说

让安安举起写着指定文字的素描本。

```text
安安说 "吾辈今天也要元气满满！" 开心
```

- 格式：`安安说 文本 [表情]`，文本含空格时用引号包裹。
- 表情可选：害羞、生气、病娇、无语、开心；省略时使用默认表情。
- 正文支持 1～500 字，可用 `\n` 换行。

## 魔裁鸭梨

选择本次出场角色，把审判选项制作成游戏画面。**下面的内容需要放在同一条消息中发送。**

```text
魔裁鸭梨 希罗
【疑问】这是真的吗？
【反驳】我有不同的证据。
```

- 第一行是命令和角色名，后续每行一个选项，支持 1～6 个选项。
- 普通类型：`【疑问】`、`【反驳】`、`【伪证】`、`【赞同】`。
- 魔法类型：`【魔法:艾玛】魔女杀手`，冒号也可以写成中文 `：`。
- 第一行的角色决定右侧人物；魔法标签中的角色只决定魔法类型。
- 每个选项正文支持 1～300 字。每次都须指定角色，无需事先切换。
- 选项正文可用 `\n` 换行。
- 正文中的 `\\n` 保留为字面量，不会换行。
- 发送 `魔裁鸭梨 -h` 查看文字帮助。

![魔裁鸭梨输出示例](examples/trial.png)

## 魔裁立绘

从官方预设中选取立绘，再通过回复图片调整表情、五官和动作。

```text
魔裁立绘 梅露露
```

![魔裁立绘官方预设选择表示例](examples/sprite-picker.png)

以下是梅露露 `P1` 的完整立绘，也可以使用立绘指令和对应短码生成：

立绘成图消息会同时显示新短码和旧短码，两者都可用于调取同一套立绘。

```text
魔裁立绘 #MLL001
```

![魔裁立绘输出示例](examples/sprite.png)

| 回复内容 | 用途 |
| --- | --- |
| 预设 | 打开人物的普通和魔女化预设列表 |
| 头型 / 表情 / 眼睛 / 嘴巴 / 手臂 / 细节 | 打开对应选择表 |
| P1 / H1 / E1 / I1 / M1 / A1 / D1 | 选择预设、头型、表情、眼睛、嘴巴、手臂或细节 |
| +脸红 / -脸红 / +汗 / -汗 | 添加或移除对应细节 |
| 上一页 / 下一页 | 翻阅当前选择表 |
| 第3页 / 跳转 3 | 跳到指定页，页码范围见选择表说明 |
| 配方 | 查看当前组合与立绘短码 |

回复旧图可继续编辑旧组合；也可发送 `#MLL001 表情` 打开该短码的表情选择表。

短码格式为 `#角色拼音首字母大写xxx`，数字固定三位，例如梅露露 `#MLL001`、雪莉 `#JXL001`、希罗 `#XL001`。同时提供一串备用短码。调取立绘发送 `魔裁立绘 #MLL001`。

发送 `魔裁立绘 -h` 查看完整帮助。

## 魔裁背景

浏览背景和游戏 CG 并取得短码。普通背景短码以 `@BG` 开头，CG 短码以 `@CG` 开头。

```text
魔裁背景 场景 1
```
![魔裁背景选择表输出示例](examples/background-picker.png)

分类可选 `场景`、`插图`、`特效`、`CG`。CG 分类收录游戏插图，使用独立的 `@CGxxx` 短码；原插图分类和 `@BG` 短码仍可使用。省略分类和页码时从场景第一页开始；有短码时可以直接查看：

```text
魔裁背景 @BG001
魔裁背景 场景 2
魔裁背景 CG 1
魔裁背景 @CG001
```

![魔裁背景大图输出示例](examples/background.png)

## 魔裁对话

组合背景、立绘、官方姓名牌和正文，制作完整游戏对话画面。

```text
魔裁对话 @BG001 #MLL001 *梅露露 大家一起出发吧。
```

![魔裁对话输出示例](examples/dialogue.png)

| 内容 | 写法与规则 |
| --- | --- |
| 背景 | 指定一个背景或 CG 短码，例如 `@BG001`、`@CG001` |
| 角色 | 0～3 个立绘短码，按短码出现顺序从左到右排列 |
| 官方姓名牌 | `*角色名`，与画面中的立绘独立 |
| 不显示姓名牌 | `*none`，省略姓名牌参数也不显示 |
| 未知姓名牌 | `*?`，显示“？？？” |
| 正文 | 直接输入文字，支持实际换行或 `\n`，排版后最多三行，过长会提示缩短；`\\n` 保留为字面量 |

参数顺序可以任意排列，用空白分隔，不需要 `参数=值`。不传立绘短码时不渲染人物，背景、姓名牌和正文仍正常显示。

无人物、无姓名牌的旁白示例：

```text
魔裁对话 @BG001 *none 房间里空无一人。
魔裁对话 @CG001 *none 故事从这里开始。
```

正文要包含 `*`、`#`、`@` 开头的参数字样时，用引号包裹对应文字，或在符号前加反斜线转义。

发送 `魔裁对话 -h` 查看文字帮助。

## 魔裁证物

使用原作图鉴书页、照片框和名称装饰，制作证物详情图片。

```text
魔裁证物 %WP002
魔裁证物 %WP002 *安安的素描本 这是在现场发现的一本素描本。\n纸页上留下了尚未完成的画作。
```

![魔裁证物输出示例](examples/evidence.png)

- 必须指定一个物品短码或在同一条消息中发送一张图片，两者不能同时使用。
- 仅输入短码时，默认使用原游戏最新版本的中文证物名称和描述，较长的原版描述会自动缩小字号以完整显示；没有原版文案的物品会提示手动填写。
- 自定义文案或上传图片时，必须同时提供 `*名称` 和描述。短码、图片、名称、描述可以乱序；文字参数用空白分隔。
- 名称含空格时写成 `*"证物 名称"`。名称限一行，过长会提示缩短。
- 描述支持实际换行、`\n` 或 `<br>`，自动折行后最多十二行；`\\n` 保留为字面量。
- 描述中的 `%WP001`、`*文字` 等参数字样可用引号包裹，或在符号前加反斜线转义。
- 上传图片最大 10 MB、2000 万像素，等比放入相框；动图使用第一帧。

上传自定义图片时，把图片和下列文字放在同一条消息中发送：

```text
魔裁证物 *神秘照片 现场拍到的可疑身影。
```

发送 `魔裁证物 -h` 查看文字帮助。

## 魔裁审问

使用原作法庭透视舞台、立绘和倾斜大字，制作审问画面。

```text
魔裁审问 #MLL001 -左
这就是**证据**。
请认真回答。
```

- 一个立绘短码加一个位置参数；`-左`、`-右` 指人物所在侧，文字显示在另一侧。
- 立绘短码、位置和文字可乱序，以空白分隔。
- `**文字**` 显示为原作粉色放大强调，可在多处使用；标记必须成对闭合。
- 正文最多八行，支持实际换行、`\n` 或 `<br>`；保留原作固定字号，不自动缩字，长行请手动分行。
- 正文中的 `\\n` 保留为字面量，不会换行。
- 正文中的位置或短码字样可用引号保护。

![魔裁审问输出示例](examples/debate.png)

还可以回复生成的审问图，发送完整的鸭梨指令：

```text
魔裁鸭梨 希罗
【疑问】证据在哪里？
【反驳】这与证词不符。
```

![审问叠加鸭梨输出示例](examples/debate-trial.png)

发送 `魔裁审问 -h` 查看文字帮助。
