# 欢迎来到得分沙拉！

MORE MORE JUMP！得分沙拉是一款适合 2–6 人一起玩的轻松选牌游戏。你每回合拿牌，再想办法让自己的计分牌得分最高。完全不会玩也没关系，跟着下面的几步做就能开始。

![MORE MORE JUMP！得分沙拉](cover.png)

## 先开一局

房主发送：

`,sl cr qk cl`

这表示“创建快速、普通模式的游戏”。想玩更完整的牌量，可以把 `qk` 换成 `std`；想加入 Center 技能和任务，可以把 `cl` 换成 `mx`。

其他人发送：

`,sl j`

人齐后房主发送：

`,sl st`

开局玩家会随机决定，不一定从房主开始。想看现在轮到谁，发送 `,sl bd`。

## 你的回合要做什么？

每回合选择一个动作：

1. 从 A、B、C 三列的顶部拿一张计分牌，例如 `,sl ta A`。
2. 拿两张角色牌，例如 `,sl ta A1 B2`。两个位置要不同。

拿完以后，空出来的位置会自动补牌。你也可以在行动前或行动后，把自己的一张计分牌翻成角色牌：`,sl fl 2` 表示翻第 2 张。

行动后翻牌要快一点：下一位玩家第一次成功拿牌、翻牌或使用技能后，这个机会就结束了。看桌面、输错指令不会让机会消失。

![一回合怎么进行](turn-flow.png)

## 怎么让牌得分？

计分牌上的图案就是得分条件。常见的方式有：

- 某个角色比大家都多或都少；
- 两张或三张同角色凑成一组；
- 凑齐指定的几名角色；
- 角色数量为奇数或偶数；
- 每缺少一种角色，或每种角色达到指定数量。

同一张角色牌可以同时帮助很多张计分牌。桌面第二张图片会列出每个人的计分牌、角色图标和当前预览分数，方便你直接比较。

![几种常见的计分牌](scoring-guide.png)

## 普通模式和混合模式

普通模式只玩基础规则，适合第一次尝试。混合模式会额外给每位玩家一名 Center，并公开两项 Live Mission；熟悉普通模式后再试会更轻松。

![普通模式与混合模式](mixed-mode.png)

混合模式的技能每局只能成功使用一次。桌面和 `,sl rl` 会告诉你当前 Center 能做什么；不确定时先发送 `,sl sk` 查看提示。

![六名 Center 的技能](center-skills.png)

## 什么时候结束？

三列牌库和桌面上的角色牌都拿完时，游戏结束。系统会自动计算每张计分牌的分数，并列出排名。总分相同的时候，后完成行动的人排名更靠前。

快速局每种角色较少，适合先熟悉；标准局牌更多，变化也更多。2–6 人都可以玩，人数越多桌面越热闹。

![三列牌库和市场](market-guide.png)

## 指令小抄

所有指令都要以英文逗号 `,` 开头：

| 想做的事 | 指令 |
| --- | --- |
| 创建 | `,sl cr qk cl` |
| 加入 | `,sl j` |
| 开始 | `,sl st` |
| 拿计分牌 | `,sl ta A` |
| 拿角色牌 | `,sl ta A1 B2` |
| 翻牌 | `,sl fl 2` |
| 看桌面 | `,sl bd` |
| 看帮助 | `,sl rl` |
| 结束游戏 | `,sl sp` |

如果只是想先看看说明，直接发送 `,sl`；想重新看完整指令和技能说明，发送 `,sl rl`。

玩得开心！如果第一次拿错牌也不用担心，跟着桌面图片和预览分数慢慢调整就好。
