# 魔裁对话资源

普通对话静态画面使用游戏内背景、界面图片和姓名模板；运行时不需要游戏安装目录或 UnityPy。

- `backgrounds.json`：稳定背景短码、分类、图片路径、游戏资源标识和原资源 SHA-256。
- `backgrounds/`：253 张背景，含 62 个场景、172 张剧情插图和 19 张特效。按最长边 2560 像素导出为质量 95 的 WebP，保留透明通道。
- `authors.json`：官方简体中文姓名模板、姓名颜色、人物定位锚点和独立缩放系数。
- `ui/`：普通打印器、姓名牌、菜单、自动按钮和等待标记。

背景短码为 `@BG001` 等固定编号。追加资源时，导出器按来源标识保留旧编号；查看器排序不决定短码。

导出入口：`tools/export_manosaba_dialogue.py`。参数为游戏 Addressables bundle 目录和静态解析 evidence.json，可通过 `--output` 指定输出目录。

画布为 2560×1440，文字使用现有 SourceHanSerifSC.otf。姓名模板按游戏字号与偏移绘制。Pillow 阴影近似 TMP 材质，尚未完成游戏运行时截图的逐像素对照；不模拟语音、逐字显现或动态转场。

## 用法

```text
魔裁背景
魔裁背景 插图 2
魔裁背景 @BG003
魔裁对话 @BG003 #CEHJPSFYCU #CXZB64FR5A #CTUBQXGXGL *艾玛 今天也要好好整理证据。
魔裁对话 *? @BG010 你是谁？
魔裁对话 @BG001 *none 空荡荡的房间里，只剩下时钟的声音。
```

参数使用空白分隔，顺序任意；最多三个角色，按短码出现顺序从左到右。正文保留换行，最多三行，超出时提示缩短。姓名牌独立于人物，省略姓名牌等同于 `*none`；`*?` 显示“？？？”。正文要包含参数字样时使用引号或反斜线转义。

背景查看免费，回复九宫格 `B编号` 查看大图和短码，回复“上一页”或“下一页”翻页。制作对话图沿用 10 积分收费，发送失败退还。
