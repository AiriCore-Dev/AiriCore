# AiriCore v2.4.3
### 该仓库为 Momoi Airi qqbot 的核心组件代码
- airi_blacklist
黑/白名单服务，作用于用户/群组

- airi_choice
N选一插件

- airi_daily_check
签到插件（Momoi Airi Collection）

- airi_help
帮助文档插件（help）

- airi_llm
大模型插件，随机回复消息

- airi_mcrcon
Minecraft服管插件

- airi_new_group
Bot入群提醒消息插件

- airi_notice
提醒插件

- airi_reply
特定回复插件

- airi_roll
摇随机数插件

- airi_status
服务器状态插件

- airi_switch
后端管理插件

- airi_turtle_soup
海龟汤插件（Momoi Airi Turtle Soup）

- airi_wish_bottle
心愿瓶插件（Momoi Airi Wish Bottle）
